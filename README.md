## 广港IEPL是什么？和普通国际线路差在哪

广港IEPL是广州—香港之间的二层点到点以太网专线。以中国联通美洲公司公开的产品说明为例，IEPL基于MSTP多业务传输平台和SDN/OTN传输网，带宽从2Mbps到10Gbps灵活调整，提供严格的带宽保证、独享的客户带宽，用户之间物理隔离，延迟固定、抖动极低。这些特性，公网线路一条都给不了。

广港这个入口的价值在于物理距离。广州到香港一百多公里，光纤传播延迟是毫秒级，真实延迟的大头在两端接入和路由上。深港段的IEPL在电信商公开的线路清单里明确标注为陆地光缆，广港走廊是同样的条件——不用绕行海缆，也不用挤公网的国际出口。
